METHOD AND LIMITS

How this was measured, and its limits

The harness is the test rig: it asks the coach a fixed set of 115 questions and records every answer. BEFORE is the code just before merge 6f1e9f4 reached main on 2026-09-02, at ac8168e; AFTER is main today, coach code unchanged since 1de3dc1. Each version answered the set 3 reps each, 690 answers, on one model and one thinking budget, wait times from quiet runs only. Her record is read separately: 196 games, 185 chat replies, 46 feedback notes, the serving build inferred, not recorded. The harness cannot rate AFTER's live correctness, because it hands the coach no verified hint and an old-shaped move-by-move analysis. It never runs the search the live coach runs first. A second server's copy of her history, 1 shadow game and 3 chats, is counted nowhere else, and only 1 row exists after PRs 16/17. Ownership on harness answers is unchecked, and the chat-versus-ladder check broke on spoken moves; both stay unaudited.
