FOUNDATIONS · 03

Depth + edgeedge rule new this round

Axis one, depth: if you can press it, it pops; if it tells you something, it lies flat; if a character says it, it whispers; if it holds things, it sinks; if it isn't built yet, it's dashed. Axis two, edge (new): everything you can touch is candy, everything the machine says is sharp. The shadow law — soft things cast squishy shadows; sharp things cast hard shadows (2px 2px 0 ink@45%, zero blur, via filter drop-shadow because box-shadow dies under clip-path); flat things cast nothing. And the boundary ruling: flat = a statement, squishy = an invitation. Two sanctioned physical exceptions: crowns (rank is the edge inside the candy world) and knight ears (the cat showing).
