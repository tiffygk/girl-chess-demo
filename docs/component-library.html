FOUNDATIONS · 03

Depth + edgeedge rule new this round

Depth: if you can press it, it pops; if it tells you something, it lies flat; if a character says it, it whispers; if it holds things, it sinks. Edge: everything you can touch is candy, everything the machine says is sharp; soft things cast squishy shadows, sharp things cast hard ones (2px 2px 0 ink at 45%, zero blur, via filter drop-shadow because box-shadow dies under clip-path), flat things cast nothing, and flat = a statement, squishy = an invitation.

Sharp is the one sanctioned override of a depth tier: name plates, coordinates, and hint chips are informational but machine-voiced, so they cast hard instead of nothing, and coordinates alone take a 1px white lift, printed on the mat rather than raised off it. Two physical exceptions: crowns (rank is the edge inside the candy world) and knight ears (the cat showing).
