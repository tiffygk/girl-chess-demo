UI design laws (durable distillation of the vault spec front-end-components.md sections 2.2/3 plus owner rulings; the vault is authoritative for detail): the two-axis law — everything you can touch is candy (rounded, squishy `0 Npx 0` press shadows: buttons, inputs, thumbs), everything the machine says is sharp (Chakra Petch signal register, chamfers, hard drop-shadows: name plates, coordinates-before-the-rainbow-override, kickers); depth tiers — squishy = invitation, flat tint = statement (cards, chips, user chat bubbles), whisper = character speech (mallow's bark, coach chat bubbles — never press-shadowed, you cannot press words). Three color voices: player = cyan, mallow = magenta/pink, coach = lavender (the third seat, established increment 3.9). Magenta is the ONLY alarm color (warnings, thumbs-down) — never spend it on infrastructure status; mint is reserved exclusively for the armed-win button; glitch/split-flicker effects are rationed to machine moments; the palette is closed (no new hex values without an owner ruling). New components join this cast rather than auditioning new aesthetics — the distinctiveness budget is spent on presence and role, not novelty.
